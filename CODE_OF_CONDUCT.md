# Code of conduct

Pragu follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By taking part in this project (issues, pull requests, discussions, reviews), you agree to it.

In short:

- Be kind, patient and specific. Assume good intent, and accept feedback gracefully.
- Accessibility is about people. Talk about disabled people with respect, and never use a disability as an insult or a joke.
- No harassment, personal attacks, sexual language or imagery, or publishing anyone's private information.

## Reporting

Report anything that breaks this code to the maintainer, Florent Latifi, at **[contact to be set before v0.1]**. Reports are read only by the maintainer and handled in confidence. The maintainer may correct, warn, temporarily ban or permanently ban a participant, following the Covenant's enforcement guidelines.

Security problems go through [SECURITY.md](SECURITY.md) instead.
