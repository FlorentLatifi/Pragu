## False positives

- `target/size` on `twin-hitslop-remove` (rn-shop › product): 16 dp view, but hitSlop makes the touch area 48 dp; invisible in the accessibility tree — This target is 16×16 dp and another target is 2.3 dp away. It needs to be at least 24×24 dp, or have that much space around it.

## False negatives

- `focus/unreachable` on `seed-hidden-button` (android-compose › checkout): hideFromAccessibility(): Compose reports the node as not visible to the user, the same signal as off-screen content, so Pragu stays silent rather than guess. Its text stays readable but cannot be activated
- `state/not-exposed` on `seed-custom-checkbox` (android-compose › checkout): no role either: nothing in the tree says it is a checkbox, so a scan cannot tell it from a button. Seeing it needs a tap (crawler, M3)
- `target/size` on `seed-crowded-star-2` (android-compose › settings): 16 dp stars that touch: a touch inside a neighbour goes to the neighbour, so this star takes touches over 16 dp only. Compose reports touch areas that meet, which Pragu cannot split
- `target/size` on `seed-crowded-star-3` (android-compose › settings): as star 2
- `target/size` on `seed-crowded-star-4` (android-compose › settings): as star 2
