# rn-shop fixture

A one-screen Expo app with three seeded accessibility barriers, each next to a correct twin. Pragu scans it in tests and in Pragu Bench.

| testID | Barrier | Rule | Correct twin |
|---|---|---|---|
| `seed-unlabeled-remove` | Icon-only button with no accessible name | `name/interactive-missing` (WCAG 4.1.2) | `twin-labeled-remove` |
| `seed-low-contrast` | `#A3A3A3` text on white, 2.5:1 | `contrast/text` (WCAG 1.4.3) | `twin-good-contrast` (7.0:1) |
| `seed-tiny-dismiss` | 16×16 dp button 2 dp from another button | `target/size` (WCAG 2.5.8) | `twin-close-cart` (48×48 dp) |

Ground truth is in [`expected.json`](expected.json). The tiny button sits next to "Apply code" on purpose: WCAG 2.5.8 accepts an undersized target when nothing else is within its 24 dp spacing circle.

This app is deliberately outside the pnpm workspace and uses npm, like a real user's app.

## Build the release APK

Requires JDK 17 and the Android SDK (`ANDROID_HOME`). From the repository root:

```bash
pnpm fixture:build
```

The APK is written to `fixtures/rn-shop/android/app/build/outputs/apk/release/app-release.apk`. The `android/` folder is generated by `expo prebuild` and is not committed.
