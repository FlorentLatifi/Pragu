# rn-shop fixture

An Expo app whose screens seed accessibility barriers next to correct twins. Pragu Bench opens each screen by deep link and compares the scan with [`expected.json`](expected.json), keyed by `testID` (Android exposes it as the view's resource id).

| Screen | Deep link | Seeded barriers | Tricky correct twins |
|---|---|---|---|
| Cart | `rnshop://cart` | Unlabelled icon button; `#A3A3A3` text (2.5:1); 16 dp button 2 dp from another; checkbox role with no checked state; button hidden from accessibility | Labelled icon button; 7:1 text; 48 dp button; checkbox with `aria-checked`; hidden inner action inside a row that is one accessible control |
| Cart with dialog | `rnshop://cart?dialog=remove` | Unlabelled close button and `#AAAAAA` text (2.3:1) inside a React Native `Modal` (its own window) | The cart's three barriers, now behind the dialog: nobody can act on them while it is open, so they must not be reported |
| Product | `rnshop://product` | Two unlabelled icon buttons; white on yellow badge (1.5:1); pale SKU (2.3:1); 20 dp stepper buttons crowded together; an image TalkBack stops on but cannot name | 26 dp title at 3.4:1 (large text needs only 3:1); text over a busy "photo"; isolated 20 dp icon (WCAG spacing exception); 16 dp icon with `hitSlop` making its real touch area 48 dp; a named image; a decorative image TalkBack skips |
| Order summary | `rnshop://summary` | One-line product name that an ellipsis cuts at 200% text; text in a fixed-height box | The same name allowed to wrap; a short one-line label; a box that grows |
| Delivery form | `rnshop://form` | Home-made checkbox with no name, role or state; field labelled only by a pale placeholder (2.1:1); field whose visible label is not connected to it | Labelled field; field connected to its label with `aria-labelledby`; labelled switch; disabled button with grey text (WCAG exempts inactive components) |

The `hitSlop` twin is a known blind spot on purpose: React Native implements `hitSlop` in JavaScript, so the enlarged touch area never reaches the accessibility tree, and Pragu reports a target WCAG would pass. Keeping it in the bench keeps the published precision honest.

This app is deliberately outside the pnpm workspace and uses npm, like a real user's app.

## Build and record

Requires JDK 17 and the Android SDK (`ANDROID_HOME`). From the repository root:

```bash
pnpm fixture:build      # release APK: fixtures/rn-shop/android/app/build/outputs/apk/release/app-release.apk
pnpm bench:record       # with an emulator running: install the APK and record every labelled screen
pnpm bench:update       # re-score and publish docs/bench/results.md
```

The `android/` folder is generated by `expo prebuild` and is not committed.
