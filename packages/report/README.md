# @pragu/report

Renders a [pragu](https://www.npmjs.com/package/pragu) scan result as one self-contained, offline HTML report: screenshots with numbered signs, what a screen reader would say, a rule index, filters and the baseline diff, in light and dark themes. No dependencies, no network requests.

**Internal until 1.0:** its API may change in any minor release. Use `pragu report <pragu-result.json>` to render a report from the command line.

Source, docs and issues: https://github.com/FlorentLatifi/Pragu · Apache-2.0
