# @pragu/core

The engine behind [pragu](https://www.npmjs.com/package/pragu): the Pragu Accessibility Model, the Android adapter, the rules, the score, baselines, SARIF and the result's JSON Schema (`@pragu/core/schema/pragu-result.schema.json`).

**Internal until 1.0:** its API may change in any minor release. To scan an app, use the `pragu` command; to read results in your own tools, use the JSON result and its schema, which are versioned.

Source, docs and issues: https://github.com/FlorentLatifi/Pragu · Apache-2.0
